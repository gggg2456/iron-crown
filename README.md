# 铁与王冠 · Iron & Crown

> 中世纪「红色警戒」风格的即时战略：采集金矿、重建兵营、让长矛与弩矢重新列阵，从黑鸦公国的铁蹄下夺回被踏碎的故土。
> 纯前端 Canvas 2D 手绘等距战场，零外部依赖、离线可玩，由 Electron 打包为 Windows 独立版。

```
  赤蔷薇最后的血脉回来了 —— 身后只有三名农民、几队残兵，和一面褪色的旗。
```

## 已知问题

| 问题 | 现状 | 计划 |
| --- | --- | --- |
| **建筑夹缝里的单位会反复抖动后闪现** | 密集建筑场景 30 秒出现 `stuckTeleports=61`：两栋相邻建筑之间的窄缝可以走进去但走不出来，每次靠保命传送救出。不是阻塞性问题（不会永久卡死），但观感是「鬼畜 + 突然闪现」 | 在寻路网格里把「两侧都是阻挡格」的窄缝直接标为不可通行，比事后传送干净。排在下一个体验版本，不阻塞 v1.5.0。**注意：做性能基线对比时要把这个变量排除**——保命传送会带动位置与寻路抖动，`sepMs` / `pathDef` 会因此波动，别把它算成重构带来的性能变化 |

## v1.4.7 修复

| 问题 | 根因 | 修法 |
| --- | --- | --- |
| **超武造好却不能用、右下角无倒计时** | 超武原本要在防御栏再花 320 金「研究」一次才装备；但建筑落成时提示却写「已就绪，点右下角面板」，此时面板根本不存在（S.superKey 为空 → HUD 隐藏） | 超武建筑落成**即自动装备**本阵营超武（含 S.superCd=0 与 HUD 刷新）；防御栏三张超武科技卡改为不再显示（避免重复购买）；落成提示改为「超级武器已装备」 |
| 玩家/AI 冷却是否互相污染 | 已排查：S.superCd 玩家独占，AI 用 S.enemySuper.timer，两者从未交叉写入 | 无需修改，AI_PACE 与玩家冷却无关 |

实测：give=sunAltar → superKey="fire"、右下角面板显示「就绪」、进度条 100%；castsuper 在敌方主堡释放 → 命中 4 个目标、冷却进入倒计时 73s；赤蔷薇造雷霆尖塔不会误装备（superKey=null）。

| **单位卡在建筑上（移动也不行）** | ① 旧兜底按「逐帧位移」判卡死，被推挤来回抖动时永远不触发；② 推挤只吸附最近一条边，可能被推进另一栋建筑；③ 推完没有二次校验 | ① 改**锚点式**检测：每 0.5 秒与锚点比位移，3 秒内位移 <0.15 格即判卡死并传送到最近空地（半径 5）；② 推挤改为在四条边里挑**第一个真正空出来**的落点；③ 推完用小容差二次校验，仍卡则直接传送；④ 新增 `pushLog` 记录 `tile/blocked/from/to` |
| 单位被建筑遮挡 | 单位与建筑底边排序值相同时会画在建筑后面 | 单位排序键 `+0.25` 偏置，贴建筑正面时不再被遮 |
| **战鼓台没有模型** | `drawBuilding` 缺 `drumTower` 分支（B 表 18 个建筑里唯一漏画的一个） | 新增 `drawDrumTower()`：木台 + 立柱 + 大鼓（带脉动）+ 阵营色旗；并全量对账 B 表 18/18 都有绘制分支 |
| 超武缺少第二入口 | 只有右下角面板一个入口 | 攻城栏新增超武卡：显示图标 + 实时冷却（`就绪` / `Ns` / `未装备`），点击进入瞄准，右下角面板保留 |
| 「敌人已自动起兵」提示 | 仓库里没有这个字符串，实际是 `黑鸦军团开始自由出击` 与每波 `黑鸦第 N 波攻势` | 删除「自由出击」提示；首波改为「敌方第一波进攻即将到来」并**只弹一次**，此后每 3 波提示一次 |

实测（卡建筑）：密集建筑 6 农舍 + 4 箭塔、10 单位往返 30 秒 → `stuckList` 恒空、`stuckTeleports=61`（均为两栋相邻建筑夹住的保命传送）；强制埋人 1 次传送脱困；普通行军 0 次。实测（战鼓台）：与「无战鼓台」对照截图差异 4,805 个采样像素，确认模型已绘制。

## v1.4.0：三阵营系数（A）

最终数值 = 基础兵种表 × `UNIT_BONUS`（兵种特性）× `FACTION_MODS`（阵营系数）。**同类百分比相乘，固定值相加**（例：长戟反骑 1.4 × 青杉伤害 1.1 = 1.54）。

| 阵营 | 系数 | 体感 |
| --- | --- | --- |
| 赤蔷薇 | 剑士/骑士 生命 ×1.10、伤害 ×1.05、采集 ×1.05（长矛/长戟/英雄不吃） | 近战血厚、正面推 |
| 青杉 | 远程**单位**射程 +1（不含箭塔等建筑）、伤害 ×1.10、塔墙生命 ×1.20、建造速度 ×1.10、移速 ×0.95、骑兵移速 ×0.90 | 射程远、守家强 |
| 黑鸦 | 近战生命 ×0.90、移速 ×1.15、骑兵移速 ×1.20、训练速度 ×1.10、采集 ×0.90、**掷矛手造价 ×0.80（55→44）** | 快、脆、便宜骚扰 |

- **风险宝箱（C）**：红边骷髅箱，拾取 +800 金并立刻刷出黑鸦伏兵（4 + 波次数，上限 8，会主动进攻）；AI 只捡普通箱、不碰风险箱；普通:风险 = 3:1，场上最多 1 个风险箱
- **农民征召（B）**：选中农民按 `V` 变民兵（攻 8 / 血 100 / 采集暂停 / 20 秒复原 / 最多 3 个），不花金币但征召期不产金
实测：赤蔷薇剑士 138 血 / 骑士 253 血（长矛保持 140）；青杉长弓手射程 6.6、箭塔不变；黑鸦掷矛手 44 金、长矛兵 75 金、移速 2.13；青杉长戟对骑伤害 28×1.4×1.1 = 43.12。

| **主线剧情** | 五章各有战前剧情卡（叙事 + 作战目标）与战后尾声，终章有结局，可随时跳过 |
| **遭遇战** | 人机对打；可选起始金钱、初始步兵数、超级武器开关，双方开局即有一座主堡 |

## 快速开始

| 方式 | 做法 |
| --- | --- |
| **直接玩（完整版）** | 到 [Releases](https://github.com/gggg2456/iron-crown/releases) 下载最新的 `IronCrown-*-win64.zip`，解压后双击 `IronCrown.exe` |
| **源码运行** | `npm install` → `npm start` |
| **免安装预览** | 直接用浏览器打开 `web/story.html`，无需任何构建 |

- 运行环境：Windows 10 / 11 x64；独立版解压后约 358 MB，免安装、全程离线。
- 源码运行需要 Node.js 20+（固定 Electron 45.3.4）。

## 玩法概览

开局只有主堡、三名农民和少量部队。占矿、造农舍扩人口、建兵营出兵，顶住一波波黑鸦进攻；
五章战役逐关解锁新的兵种与工事，最终迎战黑鸦之王。

### 战役（五章）

| 章节 | 敌方特性 | 数值倾向 | 通关解锁 |
| --- | --- | --- | --- |
| 边境劫掠 | 掠夺成性 | 甲胄单薄，首波更晚 | 长戟兵 |
| 铁鸦重甲 | 重甲 | 生命 +35%、伤害 +5%、移速 −10% | 战地祭司 |
| 群鸦奔袭 | 疾行 | 移速 +25%，出兵更快 | 军械库 |
| 瘟疫投石 | 淬毒 | 伤害 +30%、生命 +20%，攻城队登场 | 弩炮塔 |
| 黑鸦之王 | 王者之怒 | 生命 +55%、伤害 +45%，最终决战 | — |

战役起始资金固定为 **1200**，主界面不提供调整入口；只有遭遇战可以自定义起始金钱。

每章开战前会先播放一张剧情卡（章节标题 + 两段叙事 + 作战目标），胜利后追加该章尾声；打通终章会显示完整结局。剧情卡可点「跳过剧情」直接开打，重开同一章不会重复播放。

### 遭遇战

从标题页「遭遇战」标签进入，与黑鸦 AI 自由对局：

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| 起始金钱 | 1000 / 2000 / 4000 / 8000 | 双方同额，默认 2000 |
| 初始步兵 | 0 / 2 / 4 / 6 / 8 | 双方相同，随机长矛 / 剑士 / 弓手 / 重弩 |
| 超级武器 | 开 / 关 | 关闭后双方都无法建造 T3 超武建筑，也没有超武卡片 |
| 难度 | 侍从 / 骑士 / 国王 | 影响 AI 出兵速度、波次规模与上限 |
| 青杉盟军 | 开 / 关 | 可选 AI 队友 |

遭遇战双方开局就有一座完工主堡，全部军备默认解锁，并启用波次攻势（战役保持原有节奏）。摧毁对方主堡即胜。

### 奖励箱

对局中每 45–70 秒在空地刷新一个宝箱（场上最多 3 个，75 秒未拾取会消失），玩家单位走近即自动拾取：

| 宝箱 | 效果 |
| --- | --- |
| 金币箱 | +200~400 金币 |
| 援军箱 | 现场召唤 2~3 名已解锁步兵 |
| 补给箱 | 全军回复 25% 生命 |
| 超武箱 | 超级武器冷却清零；未选超武或超武关闭时折算 300 金币 |

宝箱会显示在小地图上（仅视野内）。**双方都能拾取**：黑鸦的闲置单位在视野内发现宝箱会主动前往，抢到后治疗周围部队；箱子因此变成地图上的争夺点。

## 技术实现

- `web/game.js` 单文件约 4,500 行，无框架、无构建步骤、无任何 CDN 依赖。
- 菱形等距：瓦片 64 × 32，地图 56 × 56，Canvas 2D 逐帧重绘 + 深度排序。
- 战争迷雾分「实时可见」与「记忆残影」两层，瞭望塔提供全场雷达。
- 敌方 AI 为波次推进 + 建造决策；可选友军 AI 会自主造兵、支援与共享视野。
- 寻路：直线可达时直接走；被建筑或水面挡住时用 56×56 网格 A*（8 邻接、禁穿角、拐点拉直），最后的推挤与群体分离只处理贴身碰撞；路径按每帧预算错峰计算。
- 音效由 WebAudio 实时合成；单位应答语音为 12 段离线 TTS（4 类指令 × 3 变体）。
- Electron 45.3.4 + `@electron/packager` 打包，主进程开启 `contextIsolation` / `sandbox`。

## 重新打包

```powershell
npm install
npm run package                      # 输出 dist\IronCrown-win32-x64\
npm run dist                         # 额外压出 dist\IronCrown-1.1.0-win64.zip
```

## 发布到 GitHub（无需 git）

本机没有 git / gh 也能发版：`tools/publish/` 直接走 GitHub REST API（blob → tree → commit → ref → Release）。

1. `powershell -File tools\publish\start-login.ps1` —— 打印一次性设备码，浏览器授权后 token 落到 `%USERPROFILE%\.ironcrown-secrets\token.json`
2. `powershell -File tools\publish\poller.ps1` —— 轮询直到输出 `AUTH_OK`（可放后台）
3. `powershell -File tools\publish\push.ps1 -SkipRelease` —— 只推代码
4. `npm run dist` 之后再跑 `powershell -File tools\publish\push.ps1` —— 顺带把 zip 传成 Release 附件

脚本会自动跳过 `dist/`、`node_modules/`、`.git/`、`*.zip` 与截图；仓库描述、提交信息、Release 文案在 `tools/publish/meta.json`（UTF-8），支持 `{SIZE_MB}` `{SHA256}` `{LOGIN}` `{REPO}` 占位符。
